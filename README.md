# Love, Tucson ♡

A GitHub Pages-ready Tucson community/event website.

## Uploading to GitHub

Upload **all files in this folder directly into the root of your repository**:

- index.html
- blog.html
- sources.html
- .nojekyll
- README.md

This version intentionally has the CSS and JavaScript embedded inside the HTML files, so the design will not disappear if GitHub uploads only the HTML files.

## Publish

GitHub → repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Adding events

The demo events are currently embedded in `index.html`. Search for `const EVENTS` and replace the sample events with your real Tucson events.
